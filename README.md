# MoviePilot-Plugins

> MoviePilot v2 第三方插件仓库

面向 MoviePilot v2 的第三方插件仓库，用于存放和分发个人维护的 MoviePilot 插件。

## 插件列表

| 插件 ID | 插件名称 | 版本 | 简介 |
| --- | --- | --- | --- |
| `programpreview` | 四大平台节目预告 | `1.0.29` | 抓取爱奇艺、腾讯视频、芒果TV、优酷即将上线/预约节目，优化爱奇艺采集性能和平台缓存稳定性。 |
| `weiyuncookie` | 微云Cookie助手 | `0.1.44` | 支持 QQ / 微信扫码登录微云，自动提取并保存 Cookie，可检测有效性并同步到 OpenList；QQ/微信二维码截图会自动裁掉多余空白和提示文字。 |

## 快速开始

### 添加插件源

在 MoviePilot 后台 `插件` 页面中添加第三方插件源：

```
https://github.com/qsxazcv/MoviePilot-Plugins
```

### 安装步骤

1. 进入 MoviePilot 后台，打开 **插件** 页面
2. 添加第三方插件源：`https://github.com/qsxazcv/MoviePilot-Plugins`
3. 刷新插件市场
4. 搜索并安装需要的插件
5. 安装完成后进入插件详情页，根据说明填写配置并启用

> **注意**：如果插件市场刷新后没有显示新插件，请检查插件源地址是否正确、`package.v2.json` 是否可访问、插件目录是否位于 `plugins.v2/<插件ID>/`。

## 插件详情

### 四大平台节目预告

**插件 ID**：`programpreview`

**功能**：抓取爱奇艺、腾讯视频、芒果TV、优酷的即将上线/预约节目，按 Cron 周期推送通知。

**配置项**：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用插件 | 关闭 | 开启后按 Cron 周期自动执行 |
| 开启通知 | 开启 | 通过 MoviePilot 通知渠道推送结果 |
| 每次强制推送 | 开启 | 每次运行都会推送结果 |
| 立即运行一次 | 关闭 | 保存配置后立即触发一次抓取 |
| 执行周期 Cron | `0 8 * * *` | 默认每天 08:00 执行 |

**Cron 示例**：

```text
0 8 * * *      # 每天 08:00
30 21 * * *    # 每天 21:30
```

### 微云Cookie助手

**插件 ID**：`weiyuncookie`

**功能**：支持 QQ / 微信扫码登录腾讯微云，自动提取并保存 Cookie，可检测有效性并同步到 OpenList，主页与配置页默认隐藏 Cookie 明文。

**远程命令**：

| 命令 | 说明 |
| --- | --- |
| `/weiyun_login` | 启动微云扫码登录并推送二维码 |
| `/weiyun_status` | 查询微云 Cookie 状态 |
| `/weiyun_check` | 立即检测微云 Cookie 有效性 |

**配置项**：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用插件 | 关闭 | 开启插件功能 |
| 登录方式 | `QQ 扫码登录` | 支持 QQ / 微信扫码登录 |
| 浏览器模式 | `Playwright` | 可选择 Playwright 或 CloakBrowser |
| 扫码等待秒数 | `180` | 等待用户扫码登录的最长时间 |
| 启用 MP 通知 | 开启 | 使用 MoviePilot 通知渠道发送结果 |
| 自动检测 Cookie | 关闭 | 开启后按 Cron 周期检测 Cookie 有效性 |
| 检测周期 Cron | `0 */6 * * *` | 默认每 6 小时检测一次 |
| 启用 OpenList 同步 | 关闭 | 开启后可将 Cookie 写入 OpenList 存储 |
| OpenList 地址 | `http://192.168.5.100:5244` | OpenList 服务地址 |
| OpenList Token | 空 | OpenList 管理员 Token |
| 存储 ID | `2` | 需要写入 Cookie 的 OpenList 存储 ID |

**使用建议**：

- 首次使用先在插件配置页选择登录方式并执行一次扫码登录
- 如果 Telegram 直接显示的二维码无法扫码，可点击通知中的二维码链接查看原图
- 如果需要自动同步到 OpenList，请先确认 OpenList 地址、Token 和存储 ID 正确
- **安全提醒**：不要在日志、截图或 issue 中公开完整 Cookie、OpenList Token 或二维码链接中的 API Key

## 依赖说明

- `programpreview` 带有独立的 `requirements.txt`，安装后如运行环境缺少依赖请按 MoviePilot 插件依赖安装方式处理
- `weiyuncookie` 依赖 MoviePilot 运行环境中的后端浏览器能力，优先使用插件内置 Playwright

## 维护与校验

提交插件变更前，建议执行以下检查：

```bash
python3 -m json.tool package.v2.json >/dev/null
PYTHONDONTWRITEBYTECODE=1 python3 -m py_compile plugins.v2/programpreview/__init__.py plugins.v2/programpreview/preview_core.py plugins.v2/weiyuncookie/__init__.py
git status --short --branch
```

提交前确认没有误提交：

- 真实账号登录态、Cookie、Token、密钥
- 日志、缓存、临时文件、压缩包
- `__pycache__`、`*.pyc` 等运行产物
