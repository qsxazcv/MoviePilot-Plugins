# 爱奇艺探索

让 MoviePilot 探索页支持爱奇艺视频的数据浏览，可浏览爱奇艺电视剧、电影频道内容，探索卡片支持直接进入详情页与订阅。

> 兼容 MoviePilot v2 主程序
> 本地维护版：在 qsxazcv 上游版本基础上修复订阅识别链路

## 功能

- 探索页提供爱奇艺电视剧 / 电影频道数据浏览
- 探索卡片媒体身份使用 `iqiyi:<albumId>`，识别链路接入 MediaChain 分发（`get_module` 返回方法名 → 函数 dict）
- 订阅弹窗可正常查询季集信息并恢复默认「普通订阅」

## 版本更新日志

- v1.0.40：`to_media` 补 `source=iqiyi` 身份字段，修复爱奇艺探索卡片订阅弹窗因媒体库状态查询（`/mediaserver/notexists`）无法识别来源而默认「全集洗版」，恢复默认普通订阅。
- v1.0.39：本地维护版（合并 v1.0.39~v1.0.44 全部修复）：新增 `iqiyi` / `iqiyidiscover` 识别模块并接入 MediaChain 分发（`get_module` 返回方法名 → 函数 dict）；爱奇艺 vlist 接口失效时按探索页缓存或推荐接口兜底找回剧名；识别改为 `search_meta.year` 传参修复 TypeError；探索页缓存按 7 天自动清理。
- v1.0.38：上游版本，支持爱奇艺视频的数据浏览。

## 使用说明

1. 在插件市场安装并启用「爱奇艺探索」。
2. 打开探索页，选择爱奇艺数据源浏览剧集 / 电影。
3. 点击卡片进入详情，或直接点订阅；订阅弹窗会按 TMDB 身份查询季集信息。
