# 微云Cookie助手

微云Cookie助手用于在 MoviePilot 中通过后端浏览器打开腾讯微云登录页，支持 QQ / 微信扫码登录，自动提取并保存 `weiyun.com` / `qq.com` 相关 Cookie，并可同步到 OpenList。

- 适配版本：MoviePilot V3（`system_version >= 3.0.0`）
- 插件标识：`weiyuncookie`

## 主要功能

- **扫码登录**：支持 QQ / 微信扫码登录微云，登录统一使用 MP CloakBrowser。
- **二维码处理**：截图后自动按方形外接框裁剪，只保留扫码所需区域；裁剪结果不是正方形时保留原图，不会输出残缺二维码。
- **Cookie 管理**：自动提取并保存 Cookie，页面默认隐藏明文，复制需一次性授权。
- **状态总览**：展示保存状态、Cookie 数量、登录方式、检测周期与 OpenList 同步结果。
- **定时检测**：按 Cron 定期检查 Cookie 有效性，失效时推送通知提醒重新登录。
- **OpenList 同步**：支持扫码成功后自动同步、失效重登后同步，或手动同步到指定存储。
- **通知合并**：一次登录只推送一条结果摘要（含 Cookie 数量与同步状态），失败时单独告警。
- **远程命令**：支持 Telegram 等渠道通过命令触发登录、查询状态和立即检测。
- **前端可构建**：前端为 Vue 联邦组件，源码在 `src/`，构建方式见 [FRONTEND.md](./FRONTEND.md)。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/weiyun_login` | 启动微云扫码登录并推送二维码 |
| `/weiyun_status` | 查询微云 Cookie 状态 |
| `/weiyun_check` | 立即检测微云 Cookie 有效性 |

## 设置项说明

设置页按使用频率分为常驻操作栏与折叠分区：

- **常驻操作栏**：启用插件、保存后立即运行一次、保存设置
- **常用设置**：启用状态、登录方式、扫码超时（建议 180 秒，范围 30-600）
- **登录环境**：浏览器模式（仅 CloakBrowser）、无头模式、QQ 域 Cookie、登录入口、二维码公网地址
- **自动检测与通知**：检测开关与 Cron、失效提醒、登录结果通知、OpenList 同步通知
- **OpenList 同步**：地址、Token、存储 ID 及同步时机
- **运行档案**：最近状态、登录、检测与同步结果（只读）

> OpenList Token 属于敏感配置，请勿在日志、截图或 issue 中公开。

## 通知行为

一次完整扫码登录最多推送两条消息：

1. **微云扫码登录** —— 携带二维码图片与可点击链接
2. **微云 Cookie 已更新** —— 合并摘要，正文含 Cookie 数量与 OpenList 同步状态

特殊情况：

- OpenList 同步失败时，标题标注「（OpenList 同步失败）」并在正文说明原因
- 「微云登录已启动」不再单独推送，仅记录日志
- 手动触发或设置页触发的 OpenList 同步，仍会**单独推送**「微云 Cookie 已同步到 OpenList」
- 只有登录流程内的自动同步会并入登录摘要，不重复推送

## OpenList 同步

填写 OpenList 地址、管理员 Token 和目标存储 ID 后，可在扫码成功后自动将最新 Cookie 写入 OpenList 存储配置，也可在 Cookie 失效后重新登录成功时自动同步。
